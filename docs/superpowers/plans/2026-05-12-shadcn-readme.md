> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Integrate shadcn/ui across all existing components and rewrite the README to reflect the current PostgreSQL + Docker + OVH stack.

**Architecture:** Install shadcn (Tailwind v4 mode), map brand colors to shadcn CSS vars in `:root`, keep intermediate brand tokens (`brand-pale`, `brand-mid`, etc.) in `@theme` since they are used throughout components. Migrate all 8 existing component files to use shadcn primitives without changing the visual result.

**Tech Stack:** Next.js 15, Tailwind CSS v4, shadcn/ui latest, lucide-react (already installed)

function Block({ block }: { block: any }) {

      )
    case 'quickLinks':
      return (

            <Link key={i} href={link.url} className="no-underline">

4. `backup` — pg_dump vers OVH Object Storage selon cron

## Backups PostgreSQL

Le service `backup` (dans `docker/backup/`) exécute `pg_dump` et envoie l'archive compressée vers OVH Object Storage. Rotation : 7 backups journaliers, 4 hebdomadaires, 2 mensuels.

Bucket séparé du stockage médias — credentials séparés recommandés.

## Médias — OVH Object Storage

Payload stocke les uploads directement dans OVH Object Storage via `@payloadcms/storage-s3`. Activer avec `S3_ENABLED=true` et renseigner les credentials OVH.
